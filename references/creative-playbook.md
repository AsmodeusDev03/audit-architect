## 1. Arquitectura de Narrativa (Storytelling Coherente)

### La estructura de 3 actos en 60 segundos

```
ACTO 1 — Hook (0-3s):    Agarra la atención. Pregunta, shock, curiosidad.
ACTO 2 — Desarrollo (3-50s):  Problema → tensión → revelación.
ACTO 3 — Cierre (50-60s):     Solución + CTA + anticipo del siguiente.
```

### Tipos de hooks que funcionan

| Tipo | Fórmula | Ejemplo |
|:---|:---|:---|
| **Pregunta** | "¿Sabías que...?" | "¿Sabías que el 80% de los ecommerce pierden dinero en el checkout?" |
| **Controversia** | "Esto es lo que NADIE te dice..." | "Esto es lo que NADIE te dice sobre los anuncios de Meta" |
| **Resultado** | "Cómo hice X en Y tiempo" | "Cómo dupliqué mis ventas en 7 días sin gastar más" |
| **Error** | "Deja de hacer esto..." | "Deja de poner 'link en bio'. Haz esto en vez." |
| **Historia** | "El día que..." | "El día que perdí $5,000 en ads aprendí esto" |
| **Lista** | "3 cosas que..." | "3 cosas que toda landing page necesita (y la tuya no tiene)" |

### Arquetipos de marca

| Arquetipo | Voz | Funciona para... | Ejemplo |
|:---|:---|:---|:---|
| **Hero** | "Tú puedes lograrlo" | Fitness, educación, coaching | Nike |

## 2. Psicología de Masas y Tribus

### Gatillos psicológicos por objetivo

| Objetivo | Gatillo | Cómo aplicarlo |
|:---|:---|:---|
| **Urgencia** | Escasez | "Solo 20 cupos" / "Oferta termina en 24h" |
| **Confianza** | Prueba social | "2,500+ personas ya lo usan" / Testimonios |
| **Acción inmediata** | FOMO | "No te quedes fuera" / Lista de espera |
| **Credibilidad** | Autoridad | "Usado por [marca conocida]" / Casos de estudio |
| **Lealtad** | Reciprocidad | Regalar algo primero (guía, template, consulta gratis) |
| **Engagement** | Polarización segura | Pregunta que divida opiniones sin ofender |
| **Conversión** | Anclaje | Mostrar precio original tachado junto al descuento |
| **Retención** | Progreso | Barra de avance, racha, "te falta poco" |

### Evitar estos si no quieres dañar la marca

| Gatillo | Riesgo |
|:---|:---|
| Miedo excesivo | Paraliza, no convierte |
| Escasez falsa | Destruye confianza si se descubre |
| Polarización extrema | Viral negativo, boicots |

## 3. Sinergia de Canales

### El modelo de ecosistema

```
TikTok / Reels  →  DESCUBRIMIENTO  →  Viralidad, alcance masivo
Twitter / X     →  DEBATE           →  Autoridad, conversación
LinkedIn        →  CONFIANZA B2B    →  Credibilidad profesional
YouTube         →  PROFUNDIDAD      →  Search, largo plazo
Email           →  CONVERSIÓN       →  Relación directa, venta
Comunidad       →  RETENCIÓN        →  Lealtad, feedback, UGC
```

### Reglas de sinergia

1. **Nunca duplicar** — cada canal cumple un rol distinto
2. **El contenido fluye** — un video de TikTok se expande en un hilo de Twitter, que deriva en un email
3. **CTA progresivo** — TikTok: "sígueme" → Twitter: "lee el hilo" → Email: "compra"
4. **Misma historia, distinto formato** — el mismo mensaje se adapta, no se copia

### Ejemplo de ecosistema para un lanzamiento

```
Semana 1 — PRE-LANZAMIENTO
  TikTok (Diario):    Teasers de 15s "algo grande viene"
  Twitter (3x/sem):   Hilos educativos sobre el problema
  Email (1x/sem):     "Te va a interesar esto" + lista de espera

Semana 2 — LANZAMIENTO
  TikTok (Diario):    Casos reales, testimonios
  Twitter (Diario):   Hilo de lanzamiento + Q&A
  Email (3x/sem):     Oferta limitada + testimonios + último aviso

Semana 3 — POST-LANZAMIENTO
  Comunidad:          Onboarding de compradores
  Email:              Secuencia de bienvenida
  TikTok:             UGC de clientes reales
```

## 4. Agilidad Contextual (Real-Time Marketing)

### Framework R.E.A.L.

```
R — Relevancia:   ¿Esta tendencia conecta con mi marca?
E — Ejecución:    ¿Puedo publicar en < 60 minutos?
A — Autenticidad: ¿Suena a mí o suena forzado?
L — Límites:      ¿Hay riesgo de reputación?
```

### Tipos de tendencias que se pueden surfear

| Tendencia | Riesgo | Ejemplo |
|:---|:---:|:---|
| Meme viral | 🟢 Bajo | Adaptar el formato, no el mensaje |
| Noticia de industria | 🟡 Medio | Opinar con datos, no con tripas |
| Polémica social | 🔴 Alto | Solo si es 100% alineado con valores de marca |
| Trend de audio | 🟢 Bajo | Montarse al audio con contenido propio |

### Safety check previo a publicar

```
✅ ¿Va con mi tono de marca?
✅ ¿Mi audiencia lo va a entender?
✅ ¿Alguien puede sentirse atacado injustamente?
✅ ¿Estoy agregando valor o solo ruido?
⚠️ Si dudas → no publiques.
```

## 5. Generación de Copys y Creatividades

### Estructura de copy que convierte

```
HOOK — 1 línea que agarra
PROBLEMA — El dolor que resuelves
SOLUCIÓN — Tu producto/servicio
OBJECIÓN — El "pero..." más común, respondido
PROOF — Datos, testimonios, casos reales
CTA — Exactamente qué hacer ahora
```

### Biblioteca de CTAs por objetivo

| Objetivo | CTA |
|:---|:---|
| Seguir | "Sígueme para más →" |
| Guardar | "Guarda esto para cuando lo necesites" |
| Comentar | "¿Tú qué opinas? Te leo 👇" |
| Compartir | "Etiqueta a alguien que necesita ver esto" |
| Click | "Link en mi perfil / en el primer comentario" |
| Comprar | "Quedan X. Link en bio." |
| Email | "Deja tu correo y te mando la guía gratis" |

### Variantes A/B — qué testear

| Elemento | Variante A | Variante B |
|:---|:---|:---|
| Hook | Pregunta | Afirmación polémica |
| Formato | Video cara | Video texto en pantalla |
| Largo | 15s | 60s |
| CTA | "Compra ya" | "Descubre más" |
| Tono | Serio | Humor |

## 6. Psicología de Precios y Ofertas

### Estrategias de pricing psicológico

| Técnica | Ejemplo | Cuándo usarla |
|:---|:---|:---|
| Anclaje | "Antes S/200, ahora S/97" | Lanzamientos |
| Precio señuelo | 3 opciones: básico / estándar ⭐ / premium | SaaS, servicios |
| Precio impar | S/97 en vez de S/100 | Productos físicos |
| Bundle | "Llévate X + Y por S/150 (S/250 por separado)" | Aumentar ticket |
| Garantía | "Si no te gusta, te devuelvo tu dinero en 7 días" | Eliminar riesgo |
