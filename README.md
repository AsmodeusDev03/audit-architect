# 🧬 Audit Architect

**El Unicornio Digital — Auditor Forense + Creador de Campañas**

Este skill para OpenClaw transforma a tu IA en un agente híbrido: detective obsesionado con datos + psicólogo creativo que diseña campañas. No solo diagnostica — receta, crea, distribuye y mide.

---

## 🔥 ¿Qué lo hace único?

| Skill típica | Audit Architect |
|:---|:---|
| Te dice *qué* falla | Te dice *por qué* falla + *cómo arreglarlo* |
| Mira 1 canal | Traza el viaje completo del usuario |
| Copia "best practices" | Hace ingeniería inversa de algoritmos |
| Crea sin datos | Solo crea lo que los datos validan |
| No pivotea | Mata campañas fallidas en 24h |

---

## 🧭 Los 4 Modos

| Modo | Nombre | ¿Qué hace? |
|:---:|:---|:---|
| 🔍 | Forense Digital | Ingeniería inversa de algoritmos, sentimiento semántico, punto de fuga, Core Web Vitals, SEO |
| 📊 | Forense Comercial | CAC/LTV, ROAS, atribución multi-touch, flujo de caja, márgenes reales |
| 🎨 | Arquitecto Creativo | Storytelling, psicología de masas, sinergia cross-canal, real-time marketing |
| 🧬 | Fusión Completa | Ciclo cerrado: auditar → crear → distribuir → medir → pivotar |

---

## 🕵️ Competidores Automático

No pregunta "¿quién es tu competidor?". Busca automáticamente 3 competidores y analiza:

- **6 dimensiones:** web, contenido, engagement, funnel, precios, debilidades
- **Gap Analysis:** qué hacen ellos que tú no
- **Plan de ataque:** quick wins → estrategia → moonshot

```bash
# Copiar a tu directorio de skills de OpenClaw
cp -r audit-architect ~/.openclaw/workspace/skills/

# O clonar directamente
git clone https://github.com/AsmodeusDev03/audit-architect.git \
  ~/.openclaw/workspace/skills/audit-architect
```

---

## 🧰 Uso

En cualquier chat con OpenClaw, menciona el trigger:

```
"Audita mi sitio web [URL]"
"Mis ventas cayeron, ¿qué hago?"
"Quiero lanzar una campaña desde cero"
"No sé por dónde empezar"
```

La skill hace onboarding con preguntas estructuradas, busca competidores automáticamente, y entrega un plan de acción completo con quick wins + estrategia + moonshot + condiciones de pivote.

## 🚫 Límites Éticos

- No black-hat SEO ni scraping ilegal
- No duplica contenido entre canales
- No recomienda campañas sin auditar datos primero
- Inspirar ≠ Copiar — diferenciación siempre
- Todo dato numérico lleva `source_url` verificable
