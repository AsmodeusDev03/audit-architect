# 🧬 Audit Architect / El Unicornio Digital

> 🇪🇸 *El auditor forense que también crea campañas.*  
> 🇬🇧 *The forensic auditor who also builds campaigns.*

**Audit Architect** transforms your AI into a hybrid agent: a data-obsessed detective + a creative psychologist who designs campaigns. It doesn't just diagnose — it prescribes, creates, distributes, and measures.

**Audit Architect** transforma tu IA en un agente híbrido: detective obsesionado con datos + psicólogo creativo que diseña campañas. No solo diagnostica — receta, crea, distribuye y mide.

## 🔥 Why It's Different / ¿Qué lo hace único?

| Typical Skill / Skill Típica | Audit Architect |
|:---|:---|
| Tells you *what* is wrong / Te dice *qué* falla | Tells you *why* + *how to fix it* / Te dice *por qué* + *cómo arreglarlo* |
| Looks at 1 channel / Mira 1 canal | Traces the full user journey / Traza el viaje completo del usuario |
| Copies "best practices" / Copia "best practices" | Reverse-engineers algorithms / Ingeniería inversa de algoritmos |
| Creates without data / Crea sin datos | Only creates what data validates / Solo crea lo que los datos validan |
| Never pivots / No pivotea | Kills failing campaigns in 24h / Mata campañas fallidas en 24h |

## 🕵️ Automatic Competitor Intelligence / Competidores Automático

🇪🇸 **No pregunta "¿quién es tu competidor?".** Busca automáticamente 3 competidores y analiza 6 dimensiones: web, contenido, engagement, funnel, precios, debilidades. Entrega Gap Analysis + Quick Wins + Estrategia + Moonshot.

🇬🇧 **Never asks "who's your competitor?".** Automatically finds 3 competitors and analyzes 6 dimensions: website, content, engagement, funnel, pricing, weaknesses. Delivers Gap Analysis + Quick Wins + Strategy + Moonshot.

## 🔄 The Fusion Cycle / El Ciclo de Fusión

```
1. AUDIT / AUDITAR
   └─ Extract data, detect leaks, analyze sentiment
   └─ Extraer datos, detectar fugas, analizar sentimiento
         ↓
2. DIAGNOSE / DIAGNOSTICAR
   └─ Translate metrics into business problems
   └─ Traducir métricas a problemas de negocio
         ↓
3. CREATE / CREAR
   └─ Design narrative, copy, cross-channel synergy
   └─ Diseñar narrativa, copys, sinergia de canales
         ↓
4. DISTRIBUTE / DISTRIBUIR
   └─ Schedule, automate, activate triggers
   └─ Programar, automatizar, activar triggers
         ↓
5. MEASURE / MEDIR
   └─ Compare pre/post campaign KPIs
   └─ Comparar KPIs pre/post campaña
         ↓
6. PIVOT or SCALE / PIVOTAR o ESCALAR
   └─ If it works → scale. If it fails → kill in 24h, go back to step 2
   └─ Si funciona → escalar. Si falla → matar en 24h, volver al paso 2
```
